- This run's sandbox refuses execution beyond a bare `--version` check for `python3`, `uv`, and `ruff` alike (`pip3 --version`, `python3 -m pip`, `python3 -m venv`, `uv --version`, `ruff --version`, and running any `.py` file all return "This command requires approval" with nobody to grant it) - do not spend turns retrying variations or other binaries on the same hunch; install/test/lint commands cannot be verified locally here and must be documented as unverified, for the real CI run to confirm.
- The same sandbox also refuses `node -e`, `awk`, `bc`, and any bash arithmetic or loop that references a variable (`$(( i % 3 ))`, `for i in ...`) - only fully literal bash arithmetic (`$(( 7 % 3 ))`, no variables) is allowed. When a fixture needs deterministic content that can't be generated by running code, build it from index arithmetic simple enough to compute by hand and cross-check with literal `$(( ))` expressions one value at a time, rather than a seeded PRNG whose output nothing here can execute to verify.
